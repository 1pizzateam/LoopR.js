## Synopsis

[LoopR.js](https://github.com/1pizzateam/LoopR.js) is a lightweight animation and render loop manager written in TypeScript, featuring playback controls, FPS capping, and a high-precision delta clock.

- Very lightweight
- Thoroughly tested
- Works in browsers and Node.js

## Motivation

The purpose of this library is to provide a simple, robust way to manage animation frames with FPS capping, timing statistics, and loop controls.

## Installation

```bash
$ npm install @1pizzateam/loopr
```
